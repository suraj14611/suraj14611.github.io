## 📋 How to Deploy to GitHub Pages

1. **Create a GitHub Repository** under your account (`suraj14611`):
   - Go to [GitHub - New Repository](https://github.com/new).
   - Repository Name: **`suraj14611.github.io`** (for user site) or **`portfolio`** (for project site).
   - Set visibility to **Public**.

2. **Push the Code**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Sai Suraj Macharla portfolio website"
   git branch -M main
   git remote add origin https://github.com/suraj14611/suraj14611.github.io.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Navigate to your repository **Settings** -> **Pages**.
   - Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
   - Under **Branch**, select **`main`** branch and **`/ (root)`** folder, then click **Save**.
   - Your site will be live at `https://suraj14611.github.io` within a couple of minutes!
